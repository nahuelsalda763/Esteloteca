## Esteloteca ##

## ¿Qué es Esteloteca?

Nació como un proyecto personal para poner en práctica los conocimientos adquiridos durante mi formación como **Desarrollador Python Full Stack**.

Inicialmente, fue pensada como una aplicación web sencilla para gestionar mi colección de perfumes. Con el tiempo, el proyecto evolucionó hacia una plataforma más completa, orientada a múltiples usuarios, con colecciones públicas y privadas, catálogo compartido, inteligencia artificial y sistemas de recomendación.

Además de formar parte de mi portfolio, Esteloteca representa mi proceso de aprendizaje y la forma en que combino mis conocimientos de programación con el apoyo de herramientas de IA para desarrollar una aplicación cada vez más sólida y funcional.

# Objetivo del proyecto
**ESteloteca** permite registrar y administrar una colección personal de perfumes desde una interfaz web simple, facil de usar para el público en general.

Cada perfume puede almacenar información como:
-Marca
-Nombre
-Concentración
-Tamaño
-Imagen
-Enlace opcional a la web Fragrantica

**------ ACLARACIÓN -----**
Actualmente, Esteloteca es una aplicación de gestión CRUD pensada para uso personal. Sin embargo, al finalizar el proyecto, 
evolucionará hasta convertirse en una página web completamente funcional.

La versión final contará con las siguientes características:

-Usuarios y contraseñas: cada usuario podrá crear una cuenta y gestionar su propia colección de perfumes.
-Biblioteca pública: los usuarios podrán compartir su colección públicamente para que otras personas puedan verla, pero sin posibilidad de modificarla.
-Implementación de inteligencia artificial: la aplicación contará con una IA capaz de recomendar qué perfume utilizar según el clima de la ubicación del usuario.
-Perfumes compartidos entre usuarios: si otro usuario ya cargó previamente el perfume que estás agregando, la aplicación podrá reutilizar sus especificaciones para simplificar el proceso y evitar cargar la misma información nuevamente.
